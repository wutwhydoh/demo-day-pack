**Demo narrative (compressed) [demo]:** Two uses shown. Daily rep loop: run /start day → 40 pre-researched accounts with deep links into Aircall → Claude writes results back to the CRM → /wrap day. Notable workflow shape: non-engineer reps living in Claude Code with slash commands.
